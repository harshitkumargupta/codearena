At a conference every attendee picked up two badges with the same id number, one for the jacket and one for the bag.
At the end of the day the staff collect all badges into one box, and exactly one badge has no partner: someone left
with one of theirs. Find the id on the badge that has no partner.

### Input
The first line contains `n`, the number of badges in the box. The second line contains the `n` badge ids.

### Output
Print the id of the badge without a partner.

### Constraints
- `1 <= n <= 80001`, and `n` is odd
- `1 <= id <= 1000000000`
- Every id appears exactly twice, except one id that appears exactly once.
