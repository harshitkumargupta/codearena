A city skyline is photographed from the west: `n` towers stand in a row and their heights are listed from west to
east. A tour guide wants to point out a sequence of towers, moving only eastwards, where each tower is strictly taller
than the one before. The towers do not have to be next to each other. How many towers can such a sequence contain at
most?

### Input
The first line contains `n`. The second line contains the `n` heights from west to east.

### Output
Print the length of the longest strictly rising sequence of towers.

### Constraints
- `1 <= n <= 100000`
- `1 <= height <= 1000000`
