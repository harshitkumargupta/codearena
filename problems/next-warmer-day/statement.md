A greenhouse logs one temperature reading per day. Its gardener wants to know, for every day, how long they would
have had to wait for a strictly warmer day. For each day print the number of days until the next day with a higher
reading, or `0` if no later day is warmer.

### Input
The first line contains `n`. The second line contains the `n` daily readings in order.

### Output
Print `n` numbers separated by spaces; number `i` is the wait after day `i`.

### Constraints
- `1 <= n <= 100000`
- `-50 <= reading <= 50`
